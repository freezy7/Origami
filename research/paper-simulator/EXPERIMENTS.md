# 自由纸张实验协议与验收表

协议：2026-10-31；状态更新：2026-11-01。首轮 A4 白纸实现与实际记录见 [G1_VALIDATION.md](../../G1_VALIDATION.md)。下表区分数值检查、部分验证与未执行；**G1 整体尚未验收**。旧小狗测试不计入新内核证据。

入口：[产品定义](../../PAPER_SIMULATOR_SPEC.md)、[技术方案](../../PAPER_SIMULATOR_TECHNICAL_PLAN.md)。

## 1. 先建立能公平比较的基线

- 取两种实物纸作为样件 A／B，例如普通折纸纸与较硬纸材；记录厂家／批次、标示克重、实测厚度、尺寸和纹理方向。无可靠厚度测量时保留“未知”，不能编造校准值。
- 以 150 mm 边长为初始尺度 L；另取不同尺寸检查单位一致性。长度用米、质量用千克、时间用秒，UI 可显示毫米。
- 对每组纸记录轻弯回弹、悬垂、压折后展开三个实物观察。固定拍摄角度／尺度参照，记录测量方式和不确定度；不从单张照片反推出完整材料参数。
- 首个手机性能基线暂选现有 iPhone 14 Pro Max（连接恢复后），这不是最低支持机型承诺；记录 Release／性能分析构建配置。无法连接时保持“真机未测”，不得用模拟器替代。
- 两候选使用相同材料假设、几何、抓持轨迹、外力条件与输出采样。材料未校准时，仅可报告数值差异和可观察的质感排序，不能报告“达到实物精度”。
- 自动回放的是抓持点的连续空间轨迹和工具作用体；不指定最终折线、面片最终姿态或逐步正确答案。正式交互仍允许自由输入。

E07 的孔位、切线和轮廓由输入决定；第一轮可以只提供少数工具种类，但不能只让它们作用于为某件作品配置好的位置。

E03 中的数字是重复实验的取样条件，不是产品中允许使用的固定位置和角度。用户在正式工作区中不看到这张表，也不需要按顺序完成它。

E05 的相邻面／折痕邻域需要合理接触排除；必须记录排除规则，不能把整张纸或整层纸设为互不碰撞后宣称通过。E10 的释放稳定性以实物相同姿态为基准，实物本就不能保持的连接不能被当作稳定结构标准。

## 3. 记录的数值指标

以下是拟定的第一轮研究门槛，**不是实测结果或真实性证明**。G0 应结合测量误差冻结条件；若修改，保留原值、原因和全量结果，不能只挑好看的样例。

| 指标 | 初始建议与报告方式 |
| --- | --- |
| 面内形变 | 在 E01 的温和规定轨迹下，记录三角形材料应变分布；初始希望最大主拉伸的 P95 ≤1%，峰值 ≤2%；有破坏／失稳时单独记录，不能隐藏异常点 |
| 轮廓与质量 | 对 E07 的已知材料域切口，初始希望剩余面积相对几何期望误差 ≤0.1%；质量按剩余材料面积一致更新，碎片不能重复计算 |
| 接触 | 记录最大穿透、最小非邻接距离、穿透持续时间、碰撞漏检及层序变化；不得出现持续三角面穿越；厚度容差在选定接触算法后冻结 |
| 折痕 | 对 E02／E04 记录释放后的形状、残余角、回折所需操作及网格精度敏感性；与实物对照的偏差连同测量不确定度报告，暂不捏造统一角度公差 |
| 重网格 | 记录前后材料面积、质量、速度／动量、塑性、连接锚点和非物理能量变化；切割可释放储能，不能简单要求切前切后动能相等 |
| 持久化 | 快照内应恢复的字段与身份必须一致；比较重新模拟后的行为时使用已注明容差，不承诺跨 CPU／GPU 位级一致 |
| 交互与性能 | 首轮希望达到 60 fps，总帧预算约 16.7 ms；物理预算先按约一半评估。若只能达到 30 fps，明确标为备选研究档，不宣称达到原目标。报告 P50／P95／P99、卡顿与触控延迟，不只报平均 FPS |

固定物理时间步与显示帧率分离。实验矩阵先比较 1/60、1/120、1/240 秒与不同迭代预算，记录实际子步及积压；这些是对比参数，不是已确定配置。性能吃紧时优先调整容量／分辨率并重新核验质量，不跳过接触检查，也不悄悄让模拟变慢。

## 4. 每个结果必须附带的元数据

- 日期、实验 ID、运行编号、应用与内核代码版本、编译模式。
- OS、芯片、设备型号、是否模拟器、是否接电、起始与结束热状态。
- 实物材料记录及参数版本；哪些值实测、拟合、暂定或未知。
- 纸张数量、连通体、面数／自由度、厚度、离散精度、局部网格变化。
- 抓持轨迹或工具路径版本、输入采样方式；触屏测试另记录操作者和任务理解情况。
- 时间步、子步、迭代、接触／摩擦算法与容差、邻接排除规则。
- 数值指标、全部失败与中断、存档／撤销结果、观察结论。
- 对比中改变了哪些条件；无法公平比较时不作候选优劣结论。

文本结论可放在本目录后续 `results/` 中；原始大日志／网格快照放入忽略的 `artifacts/paper-simulator/`，所有截图与录屏统一放入忽略的 `artifacts/screenshots/paper-simulator/<运行编号>/`。当前不生成伪样本、伪分数或“已通过”模板数据。

## 5. G1 的最小可评审交付

一张没有预制折痕的白纸、桌面、自由相机、抓持／临时固定和压痕操作；可读的调试指标只在实验界面出现。至少完成 E00–E06 和 E11 的单纸部分，并做一次 E13 手势观察。初始外形可以由实验夹具生成，完整用户裁剪工具在 G2 验证。

比较候选时先完成单纸小场景，记录最小可用网格、误差、成本与失败案例。然后明确决定：继续当前路线、改进材料／接触／重网格，或转向另一候选。未通过时不启动成品库和评分，也不把固定折线动画当作替代交付。

多纸层、纸材范围及手机容量必须在结果中列明；候选库与代码的版本／许可也在实际选取时记录。协议制定时未执行；目前 G1 已有上述数值与交互记录，仍未达到完整材料校准、折痕精度和通用接触验收。其余未执行项目保持待办。
