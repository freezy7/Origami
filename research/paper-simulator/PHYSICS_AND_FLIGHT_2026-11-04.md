## 本轮实现

- 几何整理：抓翼沿已有折轴直接调角；合页可打开成 V 形；可拖折轴两端旋转、拖线身平移。改轴后重建后续材料切分；不相容的刚性折叠会保留上一有效状态。支持撤销，不增加伪造折叠步骤。
- 历史折痕与展开：保留所有折痕，按步骤展开、全部展开和恢复，继承此前实现。
- 材料：将 UV 材料域焊接为连续三角网格，从平纸逐步成形。膜能包含剪切与面内应变，带符号二面角弯曲包含塑性残余折角与弱化；释放外部成形工具后继续计算回弹。
- 接触：顶点／三角形与边／边的连续碰撞候选、耦合接触惩罚及有限次数投影；求解步回溯禁止穿层和超过数值应变界限。并非通用无条件收敛或严格 IPC 保证。
- Worker：WebAssembly 求解放到单独线程，命令顺序执行；真实材料点可抓持，释放后由材料模型响应。物理快照与几何步骤分开保存。
- 试飞：只接受通过材料、接触、稳定和成形检查的实际网格；固定室内场地，统一投掷，记录首次触地距离、滞空时间、轨迹与同条件比较。碰壁、碰顶、超时和数值失败分别标记。

修改几何折轴会重新从白纸成形；当前没有将先前实时物理状态中的全部塑性变量转移到新拓扑。几何文件导出的是折叠步骤，物理快照保存在当前浏览器。多层成形与任意改轴后的物理可达性仍未完整验收。

## 可复现实验

```sh
npm run typecheck
npm test
npm run test:paper
npm run build:web
npm run test:web-bundle
npm run test:web-kernel
npm run test:material-folding
npm run test:material-wasm
npm run test:material-session
```

`test:material-folding` 和 `test:material-wasm` 是完整材料验收，失败时退出码为 1，并在报告中写入 `acceptance.passed=false`、`flight=null`。它们不能被基础测试全部通过所替代。`test:material-session` 使用前一步生成的 WASM 快照，检查正式客户端与 Worker 分发器的离线集成；不替代浏览器 Worker 部署和页面验收。输入、快照、网格和报告位于被 Git 忽略的 `artifacts/material-flight/`；脚本和解析程序纳入版本控制。

原生 8 步夹具有 157 个材料点、260 个三角形，A4 面积 0.06237 m²，质量 4.9896 g。WebAssembly 复验使用同一平纸网格、1344 次成形步和释放静置；记录源码／WASM 哈希。

基础检查包括 38 项 TypeScript 测试、333 项原生检查，以及实际 Creator 输出的合页直接拖开、折轴平移／旋转、撤销和历史回放。WebAssembly／原生的 28 命令抓纸回归保持 1 mm 差异门槛；Web 默认步长细化为 1/240 s 后最大差异约 0.68 mm。Worker 分发器检查单次初始化、队列顺序、坏快照不污染状态和后续命令恢复。这些均为程序检查，不是浏览器验收。

材料门槛不只检查末帧：定期审计成形和回弹过程中的交叉、厚度残差，并逐步检查应变。此前 WebAssembly 复验记录：峰值应变约 2%，末帧约 0.10%，零交叉，释放后平均位移约 5.15 mm，末帧最大速度约 0.0072 m/s；但目标形状 RMS 偏差约 62.9 mm，**因此最终判定失败**。该次未通过形状检查的轨迹不作为飞机成绩。

## 试飞模型与固定条件

场地 30 × 12 × 6 m；质心高度 1.5 m；初速度 6 m/s；抛出角 8°；纸形初始俯仰 12°；静风；空气密度 1.225 kg/m³；重力 9.81 m/s²。标准版本为 `indoor-30m-flatplate-v1`，材料方案为 `a4-80gsm-shell-v3`。比较记录同时筛选这两个版本。

模型将定型纸形视为刚体，按实际材料面积计算质量、重心和惯量，以双面平板的准稳态压力与摩擦估算平移／转动；局部叠层遮挡减少内部纸面的气动力重复计算。数值步长上限 1/480 s，角速度较高时进一步细分。首次顶点触地使用插值定位；能量异常或发散会使成绩无效。

它没有计算飞行中的纸面弹性变形、湍流或实测翼型系数，不能当作实物距离预测。材料厚度、刚度、屈服和摩擦也没有实测校准。气动力对系数和试验数据的依赖可参考 [NASA 升力方程说明](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/lift-equation-2/)；当前实现没有声称复现已标定的纸飞机气动模型。

## 剩余阻碍

1. 修复第三个有效折叠开始的叠层成形停滞。提高外部工具刚度、扩大接触求解余量、分层目标偏移和保留约 5° 开口的试验没有解决目标偏差，已撤回，保留严格的形状门槛。需要解决有限厚度叠层的折轴路径与接触可行运动，而非继续增大压折力。
2. 对任意改轴后的多层纸形进行物理可达性和状态转移验收。
3. 浏览器恢复访问后，逐项实操直接拖翼、V 形合页、折轴改位、释放回弹、刷新恢复与固定场地操作。
4. 完整成形通过后，再取得纸飞机统一条件飞行成绩；实物对照与材料／气动标定属于更高一级的准确性验证。
